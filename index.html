POWERSHELL PROJECT

Microsoft 365 Support Toolkit

A PowerShell-based diagnostic toolkit designed to simplify Microsoft 365 and Exchange Online troubleshooting through a structured interface. The toolkit brings together common diagnostic workflows into a single environment, helping reduce repetitive investigation steps and providing structured technical output.

PowerShell Exchange Online Microsoft Graph WPF / XAML Entra ID
Toolkit Interface WPF / XAML
Diagnostic Output PowerShell

What it does

  • Retrieves mailbox information, mailbox statistics and mailbox permissions for Microsoft 365 users.
  • Inspects Inbox Rules and forwarding configuration to identify unexpected or problematic mail flow behaviour.
  • Provides Mail User Overview diagnostics combining Exchange Online and Microsoft Graph information.
  • Provides recipient provisioning diagnostics to investigate and resolve Recipient Object Failures and provisioning-related issues.
  • Investigates ambiguous or incorrectly provisioned recipient objects using Exchange Online provisioning diagnostics.
  • Checks and analyses Exchange Online recipient and mailbox configuration during troubleshooting.
  • Uses Microsoft Graph and Exchange Online PowerShell to collect technical information from Microsoft 365 services.
  • Runs predefined Microsoft 365 and Exchange Online diagnostic workflows from a single WPF/XAML interface.
  • Centralises common Microsoft 365 troubleshooting workflows into a single support toolkit.
  • Produces structured technical output to help analyse issues, identify configuration problems and streamline repetitive investigations.

Why I built it

Microsoft 365 troubleshooting often requires running several commands, checking different services and collecting information from multiple places before an issue can be understood.


I built this toolkit to bring those repetitive investigation steps together in a single interface. It combines PowerShell automation, Exchange Online and Microsoft Graph diagnostics with a simple WPF/XAML interface.


The goal is to make technical investigations faster, more structured and easier to repeat while continuing to expand the toolkit with additional Microsoft 365 diagnostics.
